# PunchingOperation
An extension that demonstrates the ability to make your own operation, your own toolpath calculation solver in ENCY using an external module.
This example makes real Punching operation which calculates 6 degree of freedom toolpath. The user can define set of planar curves like rectangles, stars or circles in the Job assignment. The operation recognizes shape, corners of each shape and orients the punch end effector to match the corners on the punch with the corners on the original outline.

## Installation instructions:
1. Select the latest version and download the "PunchingOperationExtension.dext" from the Assets section.
https://github.com/EncySoftware/PunchingOperation/releases

2. Download and install recommended ENCY version (as indicated in the downloaded extension release description)

3. Double click on the downloaded "PunchingOperationExtension.dext" file for automatic installation or install it manually from Extansions page of the CAM system's Setup window.

4. Run ENCY

5. Then "Punching" operation will appear in the "Spray" section
